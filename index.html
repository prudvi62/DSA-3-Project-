Theory & Concepts

Algorithm Explanation

How suffix arrays and Longest Common Prefix arrays solve repeated substring detection efficiently.

Data Structure

Suffix Array

A Suffix Array stores the starting positions of all suffixes of a document in lexicographically sorted order. By grouping identical prefixes together in adjacent positions, pattern searching and repetitive structure identification become highly optimized.

Construction: O(n log² n) / O(n)
Kasai's Algorithm

Longest Common Prefix (LCP)

The LCP array stores the length of the longest common prefix between adjacent suffixes in the sorted suffix array. Kasai's algorithm computes this entire array in linear O(n) time by taking advantage of prefix relationships between consecutively positioned suffixes.

Kasai Complexity: O(n) time, O(n) space
Detection

Repeated Substrings

Any substring that occurs at least twice in a document must appear as a common prefix of at least two different suffixes. Therefore, inspecting LCP values equal to or exceeding the minimum length immediately reveals repeated substrings without exhaustive substring generation.

Extraction: O(n) scan over LCP
Baseline Comparison

Naïve Approach

The naïve method checks candidate substrings across all combinations of starting indices and lengths. Each candidate requires scanning the remainder of the document with string comparison, creating combinatorial overhead that scales poorly for large documents.

Naive Complexity: O(n²) to O(n³)
